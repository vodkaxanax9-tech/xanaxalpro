# Telegram Username Checker Bot

Бот для проверки занятости юзернеймов для БОТОВ в Telegram.

## Функции

- Проверка базовых юзернеймов (без суффиксов)
- Автоматическая генерация вариантов с суффиксами bot/_bot
- Прогресс-индикатор проверки в реальном времени
- Пакетная проверка до 10 юзернеймов за раз
- Разделение результатов на свободные и занятые

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите бота:
```bash
python bot.py
```

## Использование

Отправьте боту базовые имена для проверки:
```
zalupa122
koch121
fog229
```

Или через пробел/запятую:
```
zalupa122, koch121, fog229
```

## Токен

Бот использует токен: `8600434908:AAFTBs9AtTGzGDMGOd1L1N2r4ooUokPvnRM`

## Логика работы

1. Проверяет базовое имя (без суффиксов)
2. Если базовое имя свободно → проверяет варианты с суффиксами
3. Если базовое имя занято → варианты считаются занятыми
4. Показывает прогресс проверки в реальном времени
