# Railway Deployment Guide

## Развертывание бота на Railway

### Файлы для деплоя

Все необходимые файлы уже находятся в папке:
- `bot.py` - главный файл бота
- `requirements.txt` - зависимости Python
- `Procfile` - конфигурация запуска для Railway
- `runtime.txt` - версия Python
- `.gitignore` - исключения для Git
- `.env.example` - пример переменных окружения

### Шаги для деплоя

#### 1. Создайте GitHub репозиторий

1. Зарегистрируйтесь на [GitHub](https://github.com)
2. Создайте новый репозиторий
3. Загрузите все файлы из папки OSAAAAAA

#### 2. Деплой на Railway

1. Зарегистрируйтесь на [Railway](https://railway.app)
2. Нажмите "New Project" → "Deploy from GitHub repo"
3. Выберите ваш репозиторий
4. Railway автоматически определит Python и создаст проект

#### 3. Настройте переменные окружения

1. В Railway перейдите в "Settings" → "Variables"
2. Добавьте переменную:
   - **Name**: `BOT_TOKEN`
   - **Value**: `8600434908:AAFTBs9AtTGzGDMGOd1L1N2r4ooUokPvnRM`

#### 4. Запуск

Railway автоматически запустит бота. Он будет работать 24/7!

### Токен бота

Используйте токен: `8600434908:AAFTBs9AtTGzGDMGOd1L1N2r4ooUokPvnRM`

### Troubleshooting

Если бот не работает на Railway:
1. Проверьте логи в Railway dashboard
2. Убедитесь что переменная `BOT_TOKEN` установлена правильно
3. Проверьте что deployment успешен (зеленый статус)
4. Попробуйте перезапустить deployment (Redeploy)
